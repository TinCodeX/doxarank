# DoxaRank — Specialized SEO Agent Orchestration Architecture (Phase 4.7)

## 1. Executive Summary & Design Rationale

Phase 4.7 evolves DoxaRank's autonomous reasoning engine from a single monolithic ReAct agent into a **controlled multi-agent orchestration architecture**:

```text
                               ┌─────────────────────────────┐
                               │       User / API / UI       │
                               └──────────────┬──────────────┘
                                              │ (POST /api/seo/ai/orchestrate/)
                                              ▼
                             ┌─────────────────────────────────┐
                             │       SEOSupervisorAgent        │
                             │  - Deterministic Routing        │
                             │  - SharedContext Management     │
                             │  - Explicit Handoff Pipeline    │
                             └────────────────┬────────────────┘
                                              │
              ┌───────────────────────────────┼───────────────────────────────┐
              │                               │                               │
              ▼                               ▼                               ▼
    ┌───────────────────┐           ┌───────────────────┐           ┌───────────────────┐
    │ SEOResearchAgent  │           │SEOInvestigationAg.│           │ SEOStrategyAgent  │
    │ - GSC & Rankings  │  ──────>  │ - Root Causes     │  ──────>  │ - Adaptive Lift   │
    │ - Audit & History │ (Handoff) │ - Diagnostic Proof│ (Handoff) │ - 4-Tier Reasoning│
    │ [READ_ONLY Tools] │           │ [READ_ONLY + Inv] │           │ [Strategy Tools]  │
    └───────────────────┘           └───────────────────┘           └─────────┬─────────┘
                                                                              │
                                                                              │ (Handoff)
                                                                              ▼
    ┌───────────────────┐           ┌───────────────────┐           ┌───────────────────┐
    │SEOVerificationAg. │           │  Human Approval   │           │SEOActionPlanningAg│
    │ - Verify State    │  <──────  │  Execution Gate   │  <──────  │ - Structured Plan │
    │ - Measure Outcome │ (Post-    │ (Existing Hard    │ (Handoff) │ - Risk Bounding   │
    │ [Verifier Tools]  │  Exec)    │  Security Bound)  │           │ [Planning Tools]  │
    └───────────────────┘           └───────────────────┘           └───────────────────┘
```

### Core Principles
1. **Bounded Specialization, Not Autonomous Chaos**: Rather than spawning independent, uncoordinated bots, the supervisor explicitly coordinates logical specialized agents through strongly typed contracts.
2. **Deterministic Routing**: User intents are mapped to specialized pipelines through deterministic pattern evaluation, falling back to full-cycle analysis for general goals.
3. **Strict Tool Allowlisting**: Each specialized agent is assigned an immutable tool allowlist. Attempting to execute an unauthorized tool raises a `PermissionError`.
4. **Human-in-the-Loop Governance Boundary**: Action proposals generated by the Action Planning Agent strictly declare `requires_human_approval = True`. No agent can bypass human review or mutate live websites autonomously.
5. **Multi-Tenant Isolation**: All operations enforce `project.owner == request.user`. Data from one tenant's project is never commingled into another tenant's shared context.

## 2. Specialized Agent Contracts & Responsibilities

Every specialized agent extends `BaseSpecializedAgent` and returns a standardized `AgentResult` contract:

```json
{
  "agent": "seo_investigator",
  "status": "completed",
  "confidence": 0.825,
  "evidence": { ... },
  "findings": [
    "Investigated https://example.com/pricing: Root cause classified as 'missing_primary_heading' (HIGH certainty, confidence 88%)."
  ],
  "recommendations": [ ... ],
  "next_step": "strategy",
  "errors": [],
  "duration_ms": 142,
  "metadata": { ... }
}
```

### Agent Roles & Tool Permissions

| Agent | Class | Purpose | Tool Allowlist | Mutating? |
|---|---|---|---|---|
| **Research Agent** | `SEOResearchAgent` | Gather empirical baseline data across GSC, ranking history, site audit diagnostics, and historical outcomes. | `get_gsc_performance`, `get_gsc_queries`, `get_gsc_pages`, `analyze_gsc_performance`, `get_keyword_rankings`, `get_ranking_history`, `get_tracked_keywords`, `get_site_audit_summary`, `get_audit_issues`, `get_action_outcomes`, `get_adaptive_seo_strategy` | Strictly No |
| **Investigation Agent** | `SEOInvestigationAgent` | Classify root causes, assess diagnostic certainty, and detect affected pages and queries. | Research tools + `analyze_seo_opportunities`, `investigate_seo_opportunity` | Strictly No |
| **Strategy Agent** | `SEOStrategyAgent` | Prioritize opportunities using Bayesian smoothed historical win rates and 4-tier reasoning. | `get_adaptive_seo_strategy`, `get_action_outcomes`, `analyze_seo_opportunities` | Strictly No |
| **Action Planning Agent** | `SEOActionPlanningAgent` | Formulate deduplicated `SEOActionPlan` and `SEOAction` proposals with deterministic risk levels. | `plan_seo_actions`, `get_action_plan`, `propose_seo_action`, `get_action`, `preview_action` | Safe Internal (DB) |
| **Verification & Outcome Agent** | `SEOVerificationAgent` | Empirically verify live DOM/status changes and measure deterministic search performance lift. | `verify_seo_action`, `verify_action_plan`, `get_action_outcomes` | Safe Internal |
| **Supervisor** | `SEOSupervisorAgent` | Coordinate workflows, route tasks, manage shared context, and track handoffs. | Registry delegation | Strictly No |

## 3. Shared Context & Explicit Agent Handoffs

### Shared Context Schema
The `SharedContext` container is passed through the pipeline, accumulating domain evidence while preserving strict isolation:
- `project_id`, `project_name`, `website_url`, `user_id`
- `task_type`, `task_goal`, `target_url`, `target_query`, `correlation_id`
- `evidence`: Empirical data snapshots accumulated by Research Agent.
- `investigation_findings`: Root cause diagnostics accumulated by Investigation Agent.
- `strategy_signals`: Bayesian win rates and prioritization weights from Strategy Agent.
- `action_proposals`: Formal action proposals from Action Planning Agent.
- `verification_results` & `outcome_measurements`: Proof and lift data from Verification Agent.
- `agent_results_history`: Auditable trail of all agent executions with timings and confidences.

### Deterministic Routing Table

```python
ROUTING_WORKFLOWS = {
    "research": ["seo_researcher"],
    "investigate": ["seo_researcher", "seo_investigator", "seo_strategist"],
    "strategy": ["seo_researcher", "seo_strategist"],
    "plan": ["seo_researcher", "seo_investigator", "seo_strategist", "seo_action_planner"],
    "verify": ["seo_verifier"],
    "full_cycle": ["seo_researcher", "seo_investigator", "seo_strategist", "seo_action_planner"]
}
```

## 4. End-to-End Workflow Example

### Scenario: "Investigate why a high-value page lost rankings"

1. **User / System Trigger**:
   - `POST /api/seo/ai/orchestrate/` with `task="Investigate ranking drop on /features"` and `target_url="https://domain.com/features"`.
2. **Supervisor Routing**:
   - Deterministic router matches keyword `"drop"` -> routes to `investigate` workflow (`["seo_researcher", "seo_investigator", "seo_strategist"]`).
   - Emits `seo.agent.routing.started` and `seo.agent.routing.completed`.
3. **Step 1: Research Agent**:
   - Fetches GSC performance for `/features` (e.g. 14,000 imps, CTR dropped from 3.2% to 1.4%).
   - Fetches site audit diagnostics (e.g. missing primary H1 tag detected).
   - Writes to `context.evidence` and yields `AgentResult(confidence=0.90, next_step="investigation")`.
   - Supervisor emits `seo.agent.handoff` (`seo_researcher` ➔ `seo_investigator`).
4. **Step 2: Investigation Agent**:
   - Executes `SEOInvestigationService` on `/features`.
   - Diagnoses root cause: `missing_primary_heading` (certainty: `HIGH`).
   - Writes to `context.investigation_findings` and yields `AgentResult(confidence=0.88, next_step="strategy")`.
   - Supervisor emits `seo.agent.handoff` (`seo_investigator` ➔ `seo_strategist`).
5. **Step 3: Strategy Agent**:
   - Evaluates domain historical performance using Bayesian smoothing (e.g. heading optimizations historically achieved 75% win rate on this domain).
   - Calibrates priority adjustment (+0.07).
   - Writes to `context.strategy_signals` and yields `AgentResult(confidence=0.85)`.
6. **Step 4: Action Planning Agent** (if workflow includes planning):
   - Synthesizes `SEOActionPlan` and `SEOAction` (`OPTIMIZE_HEADING`).
   - Sets `requires_human_approval = True`.
   - Halts at the human approval gate.
7. **Human Approval Gate**:
   - Project owner inspects before/after preview diff and clicks "Approve".
8. **Controlled Execution**:
   - Mutation executor deploys verified fix.
9. **Verification & Outcome Agent**:
   - `SEOActionVerifier` checks live DOM to confirm `<h1>` tag is present (status: `VERIFIED`).
   - `SEOOutcomeMeasurementService` monitors 14-day post-deployment search console metrics.
   - Updates domain historical win rate in adaptive strategy service.

## 5. REST API Reference

### 5.1 Execute Orchestration
- **Endpoint**: `POST /api/seo/ai/orchestrate/`
- **Permissions**: Authenticated Project Owner
- **Request Body**:
  ```json
  {
    "project_id": 1,
    "task": "Investigate why organic clicks declined on /pricing",
    "target_url": "https://example.com/pricing",
    "target_query": "saas pricing"
  }
  ```
- **Response**: Full `SharedContext` JSON payload including `correlation_id`, `status`, `evidence`, `investigation_findings`, `strategy_signals`, `action_proposals`, and `agent_results_history`.

### 5.2 List Specialized Agents
- **Endpoint**: `GET /api/seo/ai/orchestrate/agents/?project_id=<id>`
- **Response**:
  ```json

    "agents": [

        "purpose": "Gather empirical performance, ranking, audit diagnostics, and historical evidence.",

      {"workflow": "research", "description": "..."},
  ```
